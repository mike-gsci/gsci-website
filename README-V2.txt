GSCI Website Canva-Faithful Version 2

This build recreates the first 12 Canva sections using the actual element positions
and dimensions retrieved from the Canva design. It intentionally preserves the
1366 x 768 page proportions, repeated header/footer structure and two-column layouts.

The original Canva image assets are not embedded in this package because the Canva
connector exposes references/temporary thumbnails rather than downloadable permanent
web assets. Version 2 therefore recreates their tonal/photo treatment with CSS.
To make the imagery pixel-identical, export the eight source images from Canva and
place them in an assets folder in a later iteration.
